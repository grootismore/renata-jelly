# Renata Starter Pack

Attach/copy these files into the root of your Streamyfin fork.

Files:
- RENATA_PRD.md — product requirements and boundaries.
- RENATA_CLAUDE_RULES.md — persistent rules for Claude Code.
- RENATA_ROADMAP.md — phased implementation plan.
- RENATA_PLAYBACK_TEST_MATRIX.md — evidence-based playback testing.
- PROMPT_01_BASELINE.md — first prompt to give Claude Code.

Important:
1. Keep Streamyfin's existing CLAUDE.md.
2. Do not replace it blindly. Tell Claude to read both its upstream CLAUDE.md and RENATA_CLAUDE_RULES.md.
3. Start from your Streamyfin fork, not a blank Expo app.
4. Prompt 01 intentionally makes almost no code changes. Establish a working baseline first.
5. After baseline succeeds, create Prompt 02 for safe Renata rebranding.
